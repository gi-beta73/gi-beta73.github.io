Team link format

Version 1 · for sites that add an Open in Stellar Optimizer button

A team link opens one or more teams (members, builds, rotation) in Stellar Optimizer. The player previews them and imports each as a new team. Everything rides in the link: no server, API key or CORS setup on either side.

LinkJSONRotationCodeWhat happensRules

1. The link

https://stellaroptimizer.com/#/teams/import?data=<payload>

payload = "z." + base64url( deflateRaw( UTF-8 bytes of the JSON ) )
  • deflateRaw: raw DEFLATE, no zlib or gzip header. Browser: CompressionStream('deflate-raw'). Node.js: zlib.deflateRawSync.
  • base64url: base64 with - for + and _ for /, no = padding.
  • Uncompressed is also accepted: "j." + base64url( UTF-8 bytes of the JSON ).
  • The payload goes after #, so browsers never send it to a server.

2. The JSON

Smallest valid link data:

{ "format": "stellar-team", "version": 1, "teams": [ { "members": [ { "character": "Bennett" } ] } ] }

Keys are case-sensitive GOOD keys: characters, weapons, artifact sets, stats. Percent stats are written as shown in game: 26.4 means 26.4%, not 0.264.

* marks a required field. Every other field is optional and takes its default.

3. Rotation

FieldTypeDefaultRules
text *stringThe repeating rotation, ≤ 5,000 characters
openerstringA different first rotation, same syntax
pingnumber100ms, 0–500. Sets swap time (100 ms = 12 frames).
rotations"steady" or integer"steady""steady": the settled pace (rotations 3–4). 1–6: that many rotations counted from the start.

Rotation text is Who actions -> Who actions -> …. Stellar Optimizer plays it on import, so timing and buffs come from the game data. Check a rotation by pasting it into Team optimize › Rotation › Write.

  • Who: the character key, the English name, or a unique start of either (3+ letters): RaidenShogun, Raiden, rai.
  • Separators: -> (or a new line, ,, ;, →).
  • Loop: end with an action-less step (-> Xingqiu) to mark who the rotation loops back to.

Character-specific options exist, e.g. CA[beams=2] (Sandrone), CA[bullets=4] (Chasca), C3F (Mavuika), hE[stacks=1] (Beidou), N3[movement=4] (metres moved). The writer lists them.

4. Code

Build each link when the page renders and put it on a plain <a target="_blank">. Building it inside a click handler and then calling window.open after an await gets the new tab blocked as a popup.
// Browser: no library needed
async function stellarTeamLink(data) {
  const json = new TextEncoder().encode(JSON.stringify(data))
  const packed = await new Response(
    new Blob([json]).stream().pipeThrough(new CompressionStream('deflate-raw'))
  ).arrayBuffer()
  let binary = ''
  for (const byte of new Uint8Array(packed)) binary += String.fromCharCode(byte)
  const base64url = btoa(binary).replace(/\+/g, '-').replace(/\//g, '_').replace(/=+$/, '')
  return 'https://stellaroptimizer.com/#/teams/import?data=z.' + base64url
}

// <a id="open-in-stellar" target="_blank" rel="noopener">Open in Stellar Optimizer</a>
document.getElementById('open-in-stellar').href = await stellarTeamLink(data)
// Node.js (server or build time)
const zlib = require('node:zlib')
const link = 'https://stellaroptimizer.com/#/teams/import?data=z.' +
  zlib.deflateRawSync(Buffer.from(JSON.stringify(data))).toString('base64url')

A link, or the JSON itself, can also be pasted into Teams › Import.

5. What happens

  1. The link opens a preview of each team: source, members, builds, rotation, your reference, and any problems. Nothing is saved yet.
  2. Import team adds a new team. Your builds become theorycraft builds, and the rotation is played on Team optimize and KQM. The player's existing teams, characters and artifacts are never changed.
  3. On the team, the player picks Imported builds (run your builds as they are) or My builds (switch to their own characters, weapons and artifacts and optimize them). Members they don't own keep your build.

6. Rules

  • Errors stop that team from being imported, with a message; other teams in the link still import. An error is: an unknown character, weapon, set or stat key; a weapon of the wrong type; a main stat a slot can't have; sets over 5 pieces or counts other than 2 and 4; a character twice; 0 or more than 4 members.
  • Numbers out of range are clamped to it. A value of the wrong type uses the default. Both are noted.
  • Unknown fields are ignored and listed as notes, which helps catch typos. Put your own data in extensions.
  • Compatibility: new fields will be optional, so links made today keep working. A change that is not backward compatible gets a new version, and older versions stay readable. A link with a newer version than the site supports asks the player to reload.
  • Limits: 10 teams per link, 60,000 characters of payload, 512 KB of JSON after decompressing.
